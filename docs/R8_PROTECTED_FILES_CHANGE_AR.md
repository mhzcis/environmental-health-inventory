# تغيير ملف محمي في R8: `src/context/StorehouseContext.tsx`

**البند:** R8-WH-01 — كان اختيار مستودع معطّل/محذوف يتحول بصمت إلى «جميع المستودعات» ويُحفظ دون إشعار، فيمكن إصدار تقرير إجمالي دون انتباه.

**التغيير (سلوك العرض فقط، لا صلاحيات):**
- يبقى التحويل إلى `all` كما هو (مرشح عرض، ليس منح صلاحية)، لكن يُسجَّل `scopeFallback` (المعرّف والاسم السابقان) في `inventory_app_storehouse_scope_fallback_v1` ويبقى بعد التحديث/الرابط المباشر حتى يختار المستخدم نطاقاً صراحة أو يؤكد «جميع المستودعات».
- إضافة `confirmAllWarehousesScope()`؛ الاختيار الصريح الصالح يمسح الإشعار.
- لم يتغير `resolveWarehouseScope` ولا أي قاعدة تفويض.

**المستخدمون:** `AppLayout` يعرض شريط تنبيه دائماً؛ `Reports` يرفض التصدير/الطباعة أثناء وجود الإشعار، ويطبع نطاق المستودعات في عنوان Excel وبيانات PDF وشريحة العرض.

**البصمة:** حُدّث سطر الملف في `protected-files.sha256` إلى بصمته الجديدة؛ بقية الملفات المحمية دون تغيير.

**الاختبارات:** `tests/r8-warehouse-scope.test.tsx` (R8-WH-C1..C3)، `tests/reports-acceptance.test.tsx` (R8-WH-R1..R3)، و `tests/p5_warehouse_centrality.test.ts` دون تغيير.
